# Панель телеметрии «Кто заходил» — настройка

На сайте есть скрытая страница `stats.html` (её нет в меню). Она спрашивает пароль
и показывает: всего визитов, сегодня / 7 дней / месяц, график по дням, список гостей
сегодня (время, IP, устройство, браузер, страница).

Пароли: **adminer**, **adinir** (полный доступ), **adman** (только сегодня).
Сами пароли хранятся не в HTML, а в коде твоего сервера — в исходниках страницы их не видно.

---

## Способ 1 (проще, рекомендуемый): Google Таблицы + Apps Script

Нужен только аккаунт Google. 5 минут, без деплоя и без денег.
Логи визитов будут лежать в обычной таблице, которую ты всегда можешь открыть глазами.

1. Зайди на https://sheets.new — создать таблицу, назови её, например, «Проектная телеметрия».
2. Меню **Расширения → Apps Script**. Откроется редактор кода.
3. Удали всё что там есть, вставь код из файла **apps-script.gs** этого проекта, сохрани (Ctrl+S).
4. Нажми **Развернуть → Новое развертывание**:
   - шестерёнка «Тип» → **Веб-приложение**;
   - «Выполнять» → **я** (твой аккаунт);
   - «Кто может получить доступ» → **Все** (иначе сайт не сможет слать данные);
   - **Развернуть**, при запросе авторизуй скрипт (Advanced → Allow — это твой собственный скрипт).
5. Скопируй **URL приложения** вида `https://script.google.com/macros/s/XXXX/exec`.
6. Впиши этот URL в двух местах проекта:
   - `fx.js`, строка `var GAS_URL = '';`
   - `stats.html`, строка `var GAS_URL = '';`
7. Закоммить и запушь. Всё — сайт пишет визиты в таблицу (лист `visits` создастся сам),
   а `stats.html` их читает.

Как проверить: открой сайт, потом обнови `stats.html` и войди по паролю — гости должны
появиться и в таблице.

### Проверка за 10 секунд (если не работает)

Вставь в адресную строку браузера свой URL и добавь параметры:

```
https://script.google.com/macros/s/XXXX/exec?task=stats&pass=adminer
```

Что должно вернуться: `{"level":"full","visits":[]}` (или со списком визитов).

| Что видишь вместо этого | Причина | Что делать |
|---|---|---|
| Страница входа Google / «нет доступа» | Доступ развертывания не «Все» | Manage deployments → Edit → «Кто имеет доступ: **Все**» → **New** версия → Обновить |
| `{"error":"неверный пароль"}` | Паспорт не в списке | Правь `PASSWORDS` в коде и передеплой (**New** версия) |
| «Разрешение не предоставлено» / 403 | Скрипт не авторизован | Открой редактор → Развернуть → Deploy → подтверди доступ (Advanced → Allow) |
| HTML-страница с «Error» / «Exception» | URL `/dev` вместо `/exec`, либо код не сохранён | Проверь окончание `/exec`; Ctrl+S в редакторе; передеплой |
| `{"ok":true}` при `?task=log&ip=1.2.3.4&device=test&path=test` в адресной строке | Лог пишется — всё хорошо | Открой таблицу, лист `visits` — строка там |

Важно после **любой** правки кода: **Manage deployments → Edit (карандаш) → Version: New** →
Update. Старый `/exec` URL продолжает указывать на старую версию кода, поэтому правки
«не применяются».

Примечания:
- IP гость узнаёт через api.ipify.org, а устройство/браузер парсятся из user-agent на стороне
  гостя — это честный минимум, который видно любому серверу.
- Бесплатный лимит Apps Script ~900 запросов/день — для школьного сайта за глаза.
- Если меняешь пароли — правь `PASSWORDS` в apps-script.gs и делай **New** версия развертывания.

## Способ 2 (запасной): Cloudflare Worker

Если захочется точнее по-взрослому (IP и страна определяются сервером, без ipify):

1. dash.cloudflare.com → Workers & Pages → Create worker → вставь код из **worker.js**.
2. Создай KV namespace (Storage & Databases → KV) и привяжи его к воркеру с именем `STATS`.
3. Deploy → скопируй URL воркера.
4. Впиши его в `WORKER_URL` в **fx.js** и **stats.html**.

Если заполнен `GAS_URL`, сайт использует его; `WORKER_URL` работает как fallback.

## Что видит гость

Ничего: видимого счётчика на страницах нет, сбор идёт скрытым маячком из `fx.js`.
Страница `stats.html` не ссылается из меню — знаешь адрес, только ты.
Если хочешь выключить сбор совсем — удали вызов `telemetry()` из `init()` в `fx.js`.
