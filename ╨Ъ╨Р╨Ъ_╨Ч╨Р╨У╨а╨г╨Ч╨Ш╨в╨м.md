# Как загрузить новый дизайн на сайт

Новый дизайн полностью заменяет старые страницы, но использует те же
имена файлов — значит приложение на телефоне подхватит его
автоматически, пересобирать APK не нужно.

## Важно: два файла нужно взять из старого репозитория

В этом наборе НЕТ файлов `favicon.png` и `intro.mp4` — я не могу их
скачать напрямую. Их нужно просто оставить как есть, они уже лежат
в репозитории `proektnaya/proektnaya` — при загрузке новых файлов их
трогать не нужно.

## Шаги (через сайт GitHub, без установки программ)

1. Откройте https://github.com/proektnaya/proektnaya
2. Нажмите кнопку **Add file → Upload files**
3. Перетащите туда файлы из этой папки:
   - `index.html`
   - `perehod.html`
   - `site31.html`
   - `site4.html`
   - `gallery.html`
   - `style.css`
   - `app.js`
4. Внизу страницы будет надпись "Commit changes" — просто нажмите
   зелёную кнопку **Commit changes**
5. GitHub спросит, заменить ли существующие файлы с такими же
   именами — подтвердите (Replace / Commit)

Через 1–2 минуты сайт `proektnaya.github.io/proektnaya` обновится
сам, а вместе с ним и приложение на телефоне (оно просто показывает
этот сайт).

## Если хотите сначала посмотреть, не публикуя

Откройте `index.html` из этой папки прямо на компьютере (двойной клик) —
браузер покажет страницу. Правда, ссылки на другие страницы и картинки
с внешних сайтов будут работать, а вот видео `intro.mp4` и `favicon.png`
не отобразятся, пока вы не положите рядом такие же файлы из старого
репозитория.
